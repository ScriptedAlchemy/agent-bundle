# First 30 minutes

1. Acknowledge the incident and name an incident lead.
2. Capture the first known bad time and a comparable known-good baseline.
3. Check recent deploys, configuration changes, dependency status, and capacity.
4. Identify one measurable containment hypothesis and its rollback signal.
5. Update stakeholders with facts, uncertainty, owners, and the next checkpoint.

Severity is driven by user impact and recovery risk, not by alert volume.
