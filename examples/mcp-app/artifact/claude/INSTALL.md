# Install mcp-app-example

A unified service-readiness assistant with MCP, Skills, Hooks, scripts, and evaluation.

Version: `1.0.0`

Run these commands from this bundle directory.

## Claude Code

Claude Code installs this bundle through its local marketplace contract:

```sh
claude plugin marketplace add ./
claude plugin install mcp-app-example@mcp-app-example-marketplace --scope user
```

Replace `user` with `project` or `local` when that Claude scope is intended.
